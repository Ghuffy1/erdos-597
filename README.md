# Erdős 597

This repository contains the mathematical manuscript and complete formal proof
for both original clauses of Erdős problem 597.

- The unrestricted graph-target assertion is false in ZFC. A counterexample
  target can be connected and bipartite, have cardinality aleph-one and diameter
  at most three, and contain no countably infinite complete bipartite graph.
- The universal finite K4-free target assertion is independent of ZFC, relative
  to its consistency. The formal development constructs the positive and
  negative Boolean-valued models and proves the corresponding first-order
  unprovability statements.
